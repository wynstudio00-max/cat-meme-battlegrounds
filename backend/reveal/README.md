# cmbg-reveal - auto-reveal Worker for the pass cards

Serves `HashChainRandomSource` (Contracts/): every minute (cron) and on `POST /poke` (cards.html calls it right after an
`open()` is mined) it reveals every waiting card in one `revealBatch` transaction. `GET /health` shows pending requests and
the operator wallet + its ETH balance.

- The operator is its OWN wallet, generated by deploy.mjs; its key exists only as the Cloudflare secret `OPERATOR_KEY`.
  It can only reveal (cannot change the contracts or move cards). Keep a little testnet ETH on it for gas.
- The seed file stays on this PC. Only every 256th link of the hash chain goes to Cloudflare (`CHAIN_CHECKPOINTS`, ~3.5 KB),
  enough to compute any link in < 256 hashes (fits the free plan's 10 ms CPU per run; measured ~3 ms for the chain math).
- Whoever reads these secrets could predict (not choose) results. For mainnet: VRF when available, or a smaller trust surface.

## Deploy (testnet)
1. Double-click `deploy.bat` (Cloudflare login opens once). It checks the seed against the on-chain anchor, creates the
   operator wallet (first run), uploads, and writes `nft.revealApi` into `Website/config.js`.
2. Make the new wallet the operator (owner key, PowerShell in `Contracts`):
   ```
   $env:RH_TESTNET_KEY = "<owner testnet key>"
   $env:OPERATOR = "<address printed by deploy>"
   npx hardhat run scripts/set_operator.js --network robinhoodTestnet
   ```
3. Send ~0.002 testnet ETH to the operator address (MetaMask).
4. Check `https://cmbg-reveal.<subdomain>.workers.dev/health`: `operatorIsSet: true`, balance > 0.

After a new random source / seed: change `SOURCE` in wrangler.toml, run deploy with `SEED_FILE` set, then step 2 again.

## Test locally
`cd Contracts && npx hardhat node`, then `node test_local.mjs` here (deploys to the local node, 14 checks).
